Falmouth Kart

A first playable prototype using real OpenStreetMap streets and building footprints around Falmouth. Drive with the on-screen controls or arrow/WASD keys.

The yellow line is the first race circuit. This build is deliberately simple: one car, free driving, a timed lap and recognisable Falmouth geography.

Map data © OpenStreetMap contributors. Prototype only. Building data is fetched live from OpenStreetMap via Overpass.
